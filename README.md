## Requirements

- JDK 17+ (or whichever version your project requires)
- JavaFX SDK 22.0.2
- SQLite JDBC driver

## Setup

1. Clone the repository.
2. Download JavaFX SDK 22.0.2.
3. Place the JavaFX `lib` folder at:

   lib/javaFX/lib/

4. Run:

   bat/compile.bat
   bat/compile-client.bat

5. Start the load balancer, server nodes, and client using the BAT files.
